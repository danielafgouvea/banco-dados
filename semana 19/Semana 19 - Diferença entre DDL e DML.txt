4) Atividade prática – "Banco de Dados com botão Desfazer"

Crie a tabela:
CREATE TABLE contas (
    id INT PRIMARY KEY,
    titular VARCHAR(100),
    saldo DECIMAL(10,2)
);

Insira:
INSERT INTO contas VALUES
(1, 'Ana', 1000.00),
(2, 'Carlos', 500.00);

Agora simule uma transferência:

BEGIN;

UPDATE contas
SET saldo = saldo - 200
WHERE id = 1;

UPDATE contas
SET saldo = saldo + 200
WHERE id = 2;

Situação 1 – Tudo certo

COMMIT;

A transferência é confirmada.

Situação 2 – Encontramos um erro

ROLLBACK;

As alterações da transação são desfeitas.
